# TeleAgent 蜡笔小新主题

为 Windows 版 TeleAgent 提供可恢复的蜡笔小新风格界面主题。2.0 版不再只在右下角放一张头像，而是把角色、场景和配色覆盖到顶部、侧栏、主页卡片、聊天区、弹窗、空状态和底部装饰，同时保留 TeleAgent 原有功能与布局。

## 使用

1. 下载或克隆本仓库。
2. 双击 `一键安装主题.bat`。
3. 如需恢复原界面，双击 `一键卸载主题.bat`。

当前已验证 TeleAgent `2.5.2`。安装器会先生成主题归档、备份当前 `app.asar`，再关闭并重新打开 TeleAgent；卸载时会校验备份哈希后恢复。遇到未验证版本时，安装器默认停止，不会强行覆盖。

## 2.0 视觉覆盖

主题包会嵌入并注入多张矢量透明角色素材，包括小新头像、顶部探头、挥手全身、睡觉状态、小白以及草地场景条。所有素材在安装时以内嵌 data URI 写入 TeleAgent 渲染层，因此安装后不依赖仓库路径或联网加载。

视觉层覆盖：应用背景、顶部区域、侧栏、主页卡片、聊天消息、输入区、弹窗/浮层、空状态、滚动条、焦点状态以及浅色/深色模式。装饰层全部 `pointer-events: none`，不拦截点击、拖拽或输入。

## Skill

仓库采用 Skill 结构。自动化代理应先阅读 [`SKILL.md`](SKILL.md)，并使用 `scripts/test-theme.ps1` 对新版本执行不修改现有安装的离线构建测试。

## 说明

本项目是非官方界面主题，不修改 TeleAgent 的账号、会话、工具或用户数据。TeleAgent 更新可能替换主题资源，更新后应重新验证并安装。
