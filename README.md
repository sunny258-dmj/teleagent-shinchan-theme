# TeleAgent 蜡笔小新主题

为 Windows 版 TeleAgent 提供可恢复的蜡笔小新风格界面主题。当前视觉版本为 **2.2.0**，按确认后的新版预览重新设计：首页顶部采用完整的小新 + 小白场景，侧栏底部使用独立休息场景，功能卡片改为浅色漫画风面板；不再使用上一版悬空头像、右下角贴纸、绿色雾化和全局底部装饰。

## 使用

1. 下载或克隆本仓库。
2. 双击 `一键安装主题.bat`。
3. 如需恢复原界面，双击 `一键卸载主题.bat`。

当前已验证 TeleAgent `2.5.2`。安装器会保留原包的外置运行文件标记，同步更新 Electron 的 ASAR 完整性指纹，并备份 `app.asar` 与 `TeleAgent.exe`，再关闭并重新打开 TeleAgent；卸载时会校验备份哈希后恢复。遇到未验证版本时，安装器默认停止，不会强行覆盖。

由于 TeleAgent 2.5.2 把 ASAR 指纹嵌入已签名的启动程序，安装主题期间 Windows 会把 `TeleAgent.exe` 显示为“签名哈希不匹配”；卸载主题会恢复保留的原始签名文件。若设备安全策略禁止运行已修改的签名程序，请不要安装此主题。

## 2.2 视觉方向

这一版按真实 TeleAgent 首页结构重新做，不再靠大量浮动贴纸制造主题感：

- 首页顶部：淡天蓝天空、草地、奔跑的小新和小白，左侧保留标题与操作空间。
- 侧栏底部：使用较小的休息场景，不覆盖主要导航和任务列表。
- 首页卡片：奶油白、淡粉、浅绿、暖黄四种轻量底色，保留清晰的信息层级。
- 输入区：大面积白色/深色纸张面板，蓝色描边与圆角统一。
- 深色模式：保留相同结构，降低插画亮度和强调色饱和度。
- 聊天、弹窗和表单：继续使用主题变量统一，但不插入悬浮角色。

角色素材仍然在安装时以内嵌 data URI 写入 TeleAgent 渲染层，安装后不依赖仓库路径或联网加载。

## 启动修复

2.2.0 保留已经修复的 TeleAgent 启动流程：

- 保留 `dist-electron/im-service`、`better-sqlite3`、`bindings`、`file-uri-to-path` 的 `app.asar.unpacked` 标记。
- 重新打包后同步更新 `TeleAgent.exe` 中的 ASAR header SHA-256 指纹。
- 安装前备份并校验原始 `app.asar` 与 `TeleAgent.exe`。
- 卸载时恢复原始文件并再次校验哈希。

本次视觉更新没有改动上述启动修复算法，只把主题版本从 2.1.0 升级为 2.2.0，以便已安装旧主题的用户正常进入升级流程。
